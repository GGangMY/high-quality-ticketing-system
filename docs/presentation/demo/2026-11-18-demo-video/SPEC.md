# 예매 시연 영상 설계

TIME: 48.2 s × 30 fps = 1,446 frames. 음악이 시계(내레이션 없음). 녹화 시각 기준은 `tools/marks-take3.json`.

## 화면 틀

- 바탕 `#F4F0E6`(발표 덱과 같은 크림색), 오른쪽 위·아래에 흐린 파랑·노랑 빛 덩어리.
- 브라우저 창: 왼쪽 64px, 위 132px, 화면 1440×810(녹화 1920×1080을 0.75배). 노란 막대에 점 셋과 탭 이름 "이선좌 · 콘서트 예매", 주소창 없음. 3px 잉크 테두리와 14px 딱딱한 그림자.
- 단계 자막: 왼쪽 위(64, 40). 파란 "STEP n" 칩 30px + 제목 50px 900. 단계가 바뀔 때 왼쪽에서 0.4초 밀려 들어온다.
- 하린: 오른쪽 아래(1545, 600) 340×440. 바뀔 때 아래에서 0.4초 튀어 오름(back.out).
- 말풍선: 하린 위(1540, 380) 너비 344, 31px 800, 줄바꿈은 낱말 단위.

## 편집

| 영상 시간 | 녹화 시간 | 내용 |
|---|---|---|
| 3.0~11.6 | 0.2~8.8 | 홈 → 상세 → 회차 선택, 카운트다운 00:00:30 |
| 11.6~44.2 | 34.4~67.0 | 카운트다운 끝 → 대기열 → 좌석 → 결제 → 확정 → 부적 QR(끊지 않음) |

- 녹화를 끊는 곳은 11.6초 한 곳. 그 자리에 "잠시 뒤" 알약을 1.2초 띄우고 휙 소리.
- 확대: 카운트다운 1.35배(11.8~14.95초), 고른 좌석 1.6배(26.2~27.9초), 확정 티켓 1.18배(37.4~39.8초), 부적 QR 1.55배(41.2초부터 끝까지). 들어가고 나오는 데 각 0.45~0.6초, power2.inOut.

## 소리

- 음악 "Carefree"(96 BPM)를 처음부터 깔고 끝 2.5초 페이드아웃.
- 클릭 9번: 화면 속 실제 클릭 순간(녹화 `click` 표시)에 맞춰 피크가 한 프레임 뒤에 오게 둔다.
- 휙 3번: 첫 화면 → 시연, "잠시 뒤" 컷, 시연 → 엔드카드.
- 팝 4번: "열렸다!", STEP 3·4·5 칩.
- 상승음 1번: "예매가 확정되었습니다"(37.1초)에 피크.
- 쓰지 않은 것: 카운트다운 째깍 소리(실제 화면의 숫자와 어긋나기 쉬워서), 매 단계 팝(너무 많으면 틀에 박힌 느낌).
