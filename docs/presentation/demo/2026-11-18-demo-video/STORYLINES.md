# 소개 겸 시연 영상 기획안

2026-11-18 사용자 요청("토스페이먼츠 연결과 이것저것 더, 소개와 시연을 같이, 추첨 응모·당첨도")으로 세 가지를 냈고, 사용자가 A를 골랐다.

## A. 하린의 예매 하루 (선택)

- 장치와 형식: 한 사람의 하루 + 실제 화면 시연. 소개 영상 v2의 세계(하린, 밤의 방)를 잇는다.
- 흐름: 오픈 3초 전 → 억울한 일 셋 → 이선좌의 해법 셋 → 실제 화면 시연(일반 예매·토스 결제창·결제 지연 뒤 확정 → 추첨 응모·당첨·자동결제 → AI 예매 상담 → 부적) → 화면 뒤 구조와 숫자 → 엔드카드
- 첫 2초: 노트북 앞 하린 위로 "티켓 오픈까지 00:00:03"
- 모습: 발표 덱의 크림색 바탕, 두꺼운 잉크 테두리와 딱딱한 그림자, 브라우저 창 틀
- 소리: 밝은 음악(Carefree), 내레이션, 하린 대사, 클릭·휙·팝·확정 상승음

## B. 화면 앞과 화면 뒤

- 장치와 형식: 화면을 둘로 나눠 왼쪽은 사용자 화면, 오른쪽은 같은 순간의 시스템(요청 기록 패널, 대기열 순번, Kafka 이벤트, Grafana).
- 흐름: 클릭 하나마다 뒤에서 일어나는 일 → 결제 거절 뒤 좌석 반환(SAGA)·결제사 장애 뒤 재결제 같은 실패 경로 → 숫자
- 첫 2초: 화면이 둘로 갈라지며 "누르는 순간, 뒤에서는"

## C. 숫자로 시작해 화면으로 증명

- 장치와 형식: 큰 글씨 숫자가 박자에 맞춰 뜨고, 숫자마다 그것을 보여 주는 실제 화면이 이어진다.
- 흐름: "2만 2천 명이 줄을 서도" → 대기열 화면, "같은 좌석은 한 번만" → 좌석 화면, "자는 사이 당첨·결제" → 추첨 화면 → 엔드카드
- 첫 2초: 검은 화면에 "20:00:00"
