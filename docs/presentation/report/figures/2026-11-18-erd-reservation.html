ERD ① 예매 DB (reservation)

공연·좌석·대기열 선점·예매·추첨이 한 DB에 있다. 판매 판정은 schedule_seats 조건부 UPDATE와 reservation_seats 부분 유니크 인덱스

erDiagram
  venues ||--o{ venue_seats : has
  venues ||--o{ schedules : hosts
  concerts ||--o{ schedules : has
  schedules ||--o{ schedule_seats : has
  venue_seats ||--o{ schedule_seats : "회차별"
  schedules ||--o{ user_schedule_quotas : "매수 한도"
  schedules ||--o{ seat_hold_requests : "접수형"
  schedules ||--o{ reservations : has
  reservations ||--|{ reservation_seats : contains
  schedule_seats ||--o{ reservation_seats : "held by"
  reservation_seats ||--o| tickets : issues
  reservations ||--o{ reservation_status_histories : logs
  schedules ||--o| lotteries : "추첨"
  lotteries ||--o{ lottery_entries : receives
  lottery_entries |o--o| reservations : "당첨 시"

  venues { bigint id PK
    varchar name }
  venue_seats { bigint id PK
    bigint venue_id FK
    varchar section
    varchar grade "VIP R S" }
  concerts { bigint id PK
    varchar title }
  schedules { bigint id PK
    bigint concert_id FK
    timestamptz open_at "예매 오픈"
    smallint max_per_user "기본 4" }
  schedule_seats { bigint id PK
    bigint schedule_id FK
    numeric price
    varchar status "AVAILABLE HELD SOLD" }
  user_schedule_quotas { bigint user_id PK
    bigint schedule_id PK
    smallint held_count }
  seat_hold_requests { uuid request_id PK
    bigint schedule_id FK
    varchar status "REQUESTED HELD REJECTED" }
  reservations { bigint id PK
    varchar reservation_no UK
    bigint user_id "서비스 간 ID"
    varchar status "HELD CONFIRMED EXPIRED ..."
    timestamptz hold_expires_at
    varchar source "GENERAL LOTTERY" }
  reservation_seats { bigint id PK
    bigint reservation_id FK
    bigint schedule_seat_id FK "부분 유니크"
    varchar status }
  tickets { bigint id PK
    varchar ticket_no UK
    bigint reservation_seat_id FK }
  reservation_status_histories { bigint id PK
    bigint reservation_id FK
    varchar from_status
    varchar to_status }
  lotteries { bigint id PK
    bigint schedule_id FK
    int seat_count
    varchar status "OPEN CLOSED DRAWN DONE" }
  lottery_entries { bigint id PK
    bigint lottery_id FK
    bigint user_id
    varchar status "ENTERED WON WAITLISTED ..."
    int draw_rank "예비 승계 순서" }
