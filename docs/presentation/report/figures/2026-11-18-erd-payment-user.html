ERD ② 결제 DB (payment) · 사용자 DB (user) · 공통 테이블

DB 사이에는 FK가 없고 ID 값으로만 잇는다. 결제는 PG 호출 전에 pg_order_id를 저장해, 응답이 없어도 다시 조회할 수 있다

erDiagram
  payments ||--o{ payment_status_histories : logs
  payments ||--o| refunds : "환불"
  users ||..o{ payments : "user_id (서비스 간 ID)"
  users ||..o{ billing_keys : "user_id"

  users { bigint id PK
    varchar email UK
    varchar password_hash "BCrypt"
    varchar role "USER ADMIN" }
  payments { bigint id PK
    bigint reservation_id UK "예매당 하나"
    bigint user_id
    numeric amount
    varchar method "CARD BILLING"
    varchar status "REQUESTED APPROVED UNKNOWN ..."
    uuid pg_order_id UK "PG 호출 전 저장"
    timestamptz next_check_at "재조회 시각" }
  payment_status_histories { bigint id PK
    bigint payment_id FK
    varchar from_status
    varchar to_status }
  refunds { bigint id PK
    bigint payment_id FK "결제 1건당 1건"
    uuid pg_refund_id UK "PG 멱등키"
    varchar status "REQUESTED REFUNDED UNKNOWN ..." }
  billing_keys { bigint id PK
    bigint user_id
    varchar billing_key_enc "AES-256-GCM"
    varchar status "ACTIVE REVOKED" }
