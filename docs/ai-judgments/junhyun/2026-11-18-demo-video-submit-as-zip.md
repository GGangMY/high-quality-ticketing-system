# 제출용 "영상 압축"을 다시 인코딩으로 해석한 AI 결과를 받지 않고 원본을 zip으로 묶게 함

## 맥락
- 해결하려던 작업: 시연 영상(ISE-311, 1분 43초, 44MB)을 결과 제출에 올리려고 "영상 압축해서 좀 줄래? 제출해야해서"라고 요청했다.
- AI 활용 방식: Claude Code에 파일을 만들어 달라고 했다.

## AI 제안
"압축"을 파일 크기를 줄이는 다시 인코딩으로 해석했다. x264 CRF 26으로 1080p(10.6MB)와 720p(6.6MB) 두 파일을 만들고, 화면 글자가 읽히는지 확인한 뒤 1080p를 권했다.

## 판단
- 결과: 거부
- 판단자: junhyun
- 근거: "아니 이런 압축말고 zip으로 압축!" 제출 양식이 zip 파일을 받는다.
- 검토한 대안: 없음

## 반영
원본 영상(화질 손실 없음)을 `시연영상_05조_이선좌.zip` 하나로 묶었다. 결과보고서 파일 이름(`결과보고서_05조_이선좌.pdf`)과 같은 규칙이다. 다시 인코딩한 두 파일은 휴지통으로 옮겼다.

## 검증
zip 안 파일 이름의 UTF-8 표시(0x800)를 확인했고, 풀어 낸 파일이 원본과 바이트 단위로 같다(`cmp`). 다른 운영체제에서 한글 이름이 깨지지 않게 하려는 확인이다.

## 판단 이력
- 2026-11-18 거부: 다시 인코딩 대신 원본을 zip으로 묶게 함
